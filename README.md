# Coffee Chain Data Analysis

## Overview
This project analyzes a Coffee Chain dataset using Microsoft Excel and Pivot Tables. The analysis focuses on sales performance, profit margins, market contribution, store performance, product performance, and cost analysis.

## Objectives
- Identify markets contributing the least and most to sales.
- Determine product types with the highest sales contribution.
- Analyze store performance based on sales and profit.
- Compare COGS (Cost of Goods Sold) across years.
- Evaluate profit margins and expenses.
- Discover high-performing states and markets.

## Dataset Information
The dataset contains information about:
- Store ID
- Date
- Market and Market Size
- Product Line and Product Type
- Sales
- Profit
- COGS
- Marketing Expenses
- Other Expenses
- State

## Analysis Performed

### 1. Market Contribution Analysis
Determined the percentage contribution of each market to total sales.

### 2. Product Type Sales Analysis
Identified product types with the highest contribution to overall sales.

### 3. Store Performance Analysis
- Store with highest sales
- Store with highest profit
- Store with highest expenses

### 4. Profit Margin Analysis
Compared profit margins across different years.

### 5. COGS Analysis
Analyzed Cost of Goods Sold (COGS) for products across 2012 and 2013.

### 6. State-wise Sales Analysis
Identified states generating the highest sales across market segments.

- Market contribution percentages were calculated using Pivot Tables.
